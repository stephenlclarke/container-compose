## User-visible contract

- A provider that declares `engine.route.VolumeCreate` exposes
  `POST /v1.53/volumes/create` through the public gateway. An undeclared route
  remains fail-closed as `501` rather than being advertised optimistically.
- The controller decodes Docker `Name`, `Driver`, `DriverOpts`, and `Labels`,
  then calls one `DockerVolumeBackend`; it does not create an HTTP-specific
  volume catalogue.
- Container projects that backend onto `VolumesService`. Omitted and empty
  drivers normalize to `local`; an unavailable driver fails before name
  persistence, directory or ext4 allocation, or container mutation, and the
  Docker response is `404 {"message":"plugin \"<driver>\" not found"}`.
- The focused Docker CLI proof points `docker --host` only at the disposable
  candidate Unix socket. It proves the public gateway, provider session,
  controller, and native authority path and asserts no native volume residue.

## Explicit non-goals

This contract does not close Docker Volume `inspect`, `list`, `remove`, or
`prune`; autogenerated names; existing-volume idempotence/conflicts; complete
Docker local-driver option grammar; plugin discovery/lifecycle; non-local
providers and mounts; Compose reconciliation; devcontainer adoption; or
`use_api_socket`. Those remain independently `Queued`. Performance design is
preserved, but timing optimization and comparable-or-better claims are
post-functional; a candidate hang, timeout, or liveness-bound breach remains a
functional blocker.
