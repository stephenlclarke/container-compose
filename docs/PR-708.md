# feat(build): migrate Compose to the shared native Bazel workflow

Pull request: [708](https://github.com/stephenlclarke/container-compose/pull/708).

## Motivation

Implement the operator-approved [recoverable Bazel build request](ISSUE-build-bazel-workflow.md) without another coordinator or reference rebuilds.

## Implementation

- Native Swift product targets preserve both Package.resolved profiles and Swift package-access boundaries.
- The executable links the same ComposePlugin module intended for CLI tests; no SwiftPM build subprocess is involved.
- The family launcher and evidence/cache/storage implementation are reused from devcontainer PR [83](https://github.com/stephenlclarke/devcontainer/pull/83), with every shared executable helper bound by the consumer's byte/mode lock.
- The separate opt-in Makefile avoids legacy Makefile parsing, signing discovery or runtime lifecycle operations during native graph qualification.
- Native Go helper and Linux ARM64/AMD64 initializer products use the existing Go version and dependency pins. Both unit profiles include the six Go test targets, with nonempty case-level XML.
- Swift fixtures and resource bundles are declared; CLI/parser tests use native products. Scratch selection and same-directory atomic publication keep temporary work on the SSD without changing persistent state locations.
- A narrowly isolated local-only permission-bit test retains its assertions outside Darwin's sandbox, which strips those bits from the source fixture. All other migrated tests remain sandboxed.
- Declarative consumer inventories drive the shared test/coverage validator. Retained coverage export requires authenticated clean source evidence; the separate 90% gate binds the current consumer SHA, runtime profile and policy before checking raw line counts. No tests or builds are repeated for report export.
- Native optimized candidate packaging uses pinned rules_pkg and the existing plugin layout, with declared resources, version/dependency/capability metadata, four product hashes and an exact archive receipt. Real archive smoke tests check paths, modes, hashes, packaged version and local bundled-parser behavior. The retained archive can be restored without a build. Distribution and licence-closure readiness remain explicitly false.
- Release-note fixtures disable background Git maintenance locally before committing, preventing the observed CI temporary-repository cleanup race; their focused suite now runs under Bazel as well.
- Native dependency notices reuse fetched Go/Swift/SDK inputs with metadata-only overlays. Exact Go module/version/text inventory validation, deterministic text hashing and archive assertions prevent silently incomplete Go notice bundles; all Swift root notice variants are retained. No product pins change. Complete nested-vendor/legal closure remains explicitly unclaimed.
- Stock now executes 1,056 runtime-neutral Core cases rather than omitting the entire suite. Shared project/data/orchestration fixtures no longer require enhanced provider imports; concrete clients/models live in separate enhanced-only support files. Both build manifests retain an identical five-file provider-coupled inventory and explicit profile guards in mixed suites, while enhanced retains all 1,246 Core cases. The stock evidence policy requires the additional target and executed normalizer/process/up/run/API-socket production probes.
- Native address/thread sanitizer targets instrument the Swift/C graph, while a separate Go race target selects rules_go's race mode. A narrow declared rules_go context patch prevents incompatible Clang sanitizer runtimes from being injected through CGo. No Swift/C instrumentation, assertion or test is suppressed.
- Add internal, default-off per-run cancellation observations without changing signal/queue/termination semantics. Existing cancellation tests retain the two-second bound and both PID-absence checks, and now publish payload-free monotonic phase JSON. A normal-completion check validates observer phases and uniqueness; the new neutral test brings current Core counts to 1,057 stock and 1,247 enhanced.
