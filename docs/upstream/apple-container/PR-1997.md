## Motivation and Context

The API server reads the `.signal` XPC key as a string, but `ClientProcess.kill(_:)` sent an integer. The server consequently rejected foreground attach signals as missing. Sending the raw host number would also misdeliver signals whose Darwin and Linux numbers differ.

The companion report is [ISSUE-1941.md](ISSUE-1941.md).

## Implementation Details

- Use `Signal.platformName(_:)` to encode the canonical signal name.
- Fall back to a numeric string only when no platform name exists.
- Preserve the API server as the single Linux signal-table resolution boundary.
- Keep the production patch content-identical to the existing Apple pull request.
