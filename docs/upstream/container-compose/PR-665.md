# PR 665: fail fast on a private VM-init authority

Current publication preflight now obtains a GHCR pull token without repository
or user credentials and resolves the exact Containerization VM-init manifest.
Token acquisition and manifest lookup share a bounded retry loop, so transient
registry failures retry while a missing or private authority fails before any
CodeQL, product build, notarization, release, or Homebrew promotion work.

The existing retained initfs-artifact check remains independent and mandatory.
Together the two checks prove both source provenance and clean-install runtime
availability.

Related issue: [#664](https://github.com/stephenlclarke/container-compose/issues/664).
