## Functional reason

Dedicated prewarming materializes `rootfs.ext4` when a container is created.
The prior export path preferred that block device and could therefore bypass a
corrupt persisted `rootfs.json`. Container pull request 176 restores
metadata-first validation while retaining legacy block-device and
never-started-container fallbacks. Compose must publish that reviewed runtime
authority before the stable tag is created.
