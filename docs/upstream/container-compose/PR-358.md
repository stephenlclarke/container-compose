# Pull request 358: bound Current Demo engine readiness

## Summary

Pull request [`#358`](https://github.com/stephenlclarke/container-compose/pull/358) closes tracking issue [`#357`](https://github.com/stephenlclarke/container-compose/issues/357).

- Poll the packaged Container Engine through bounded JSON status probes before rendering the visible runtime status table.
- Bound the visible status command and expand the VHS screen wait to cover the complete bounded startup envelope.
- Terminate the recorded shell with a distinct failure marker instead of waiting for the success marker after a bounded command fails.
- Add focused regression assertions for the unattended readiness contract.

## Failure boundary

The demo remains fail closed. If the Engine never reports `running`, or if the visible status command exceeds its deadline, the readiness marker is not emitted and the workflow cannot replace the published demo asset.
