# Pull request 699: recover retained sibling branches

## Change

This pull request lets the unattended stable-release controller recover a clean retained sibling checkout that is still on a preserved non-`main` branch. The isolated transaction switches back to local `main`, fast-forwards it to freshly fetched canonical remote authority, and leaves the retained branch and its commits unchanged.

## Scope boundary

This changes retained release-transaction reconciliation only. It does not reset, delete, rewrite, or merge the preserved branch. Dirty checkouts and divergent local `main` branches continue to fail closed. Product behavior, release artifacts, signing, notarization, Homebrew formulae, and benchmark semantics are unchanged.
