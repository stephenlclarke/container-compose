## Implementation

The candidate-bound authority step already proves that the selected gate, receipt, artifact, signed tag, dependency pins, and guest init-image authority agree. Immediately after it creates the verified authority archive and sidecar, it now records only that pair through the existing locked, conflict-detecting retention tool.

For a first publication this creates a safe partial manifest which later staging completes. For an unpublished retry after stale-authority invalidation, it completes the existing manifest. The staging materialization can therefore restore the earlier package, matched runtime, highlights, and quality snapshot as one exact set. Newly built timestamp-signed bytes never reach the later conflict path.
