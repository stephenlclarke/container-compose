## Functional reason

Container background prewarming reserved a created service container's
block-backed volume before a Compose `pre_start` helper could attach it.
Container pull request 179 makes block-backed configurations ineligible for
speculative prewarming while retaining the optimization for block-free and
VirtioFS-only workloads.
