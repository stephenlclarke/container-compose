## Motivation and context

The passing `main` quality gate still retained 40 maintainability findings. Two Go findings identified real cognitive-complexity debt in security-sensitive volume initialization. The Swift findings were either small readability defects that could be corrected directly or analyzer mismatches against fixed Docker/guest protocol values and immutable public record shapes.

This change fixes maintained source where behavior can become clearer. The remaining analyzer mismatches are scoped by exact rule and resource patterns, with the rationale kept beside the SonarQube configuration. No maintained source is removed from analysis and the existing coverage exclusions are not expanded.
