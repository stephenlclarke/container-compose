# Pull request 361: remove duplicate Current Demo status probe

## Summary

Pull request [`#361`](https://github.com/stephenlclarke/container-compose/pull/361) completes tracking issue [`#357`](https://github.com/stephenlclarke/container-compose/issues/357).

- Keep the bounded JSON `engineStatus` probe as the single readiness authority.
- Remove the redundant full status-table process that could retain the cold-start terminal session after readiness had already succeeded.
- Render a concise visible Engine-running result before the existing success marker.
- Add a focused regression assertion that prevents the duplicate status process from returning.

## Failure boundary

The demo remains fail closed. If neither bounded system-start attempt succeeds or the Engine never reports `running` through a bounded JSON probe, the command emits the distinct failure marker, exits, and cannot replace the published demo asset.
