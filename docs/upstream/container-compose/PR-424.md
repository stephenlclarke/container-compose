## Compatibility and risk

This changes release orchestration only. The selected Container unit-coverage process receives the operator home because the tested legacy generic-password API does not select an explicit Keychain. Its stores disable authentication UI before reads. A fail-fast host preflight prevents a locked or unavailable Keychain from becoming an unattended interactive wait. Product artifacts and persistent Keychain state are unchanged.

The rejected disposable-Keychain design remains documented in [`ISSUE-423.md`](ISSUE-423.md) so it is not retried.
