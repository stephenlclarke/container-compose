neither registered as active nor retired through immutable archives. Initial
Workflow Enabler 12 requires this pre-existing failure to be resolved before

- Use `archived`, because the documents describe an already-shipped local
  implementation rather than an active Apple-facing proposal.
- Link to the exact published commit that first contained both documents, so
  retirement does not depend on mutable branch content.
- Make no Apple upstream write and no runtime, release, package-pin, Docker
  Compose semantic, or performance-threshold change.
- Classify `attach`, `logs`, `run`, and `up` as partial in the user-facing help
  metadata and render concise foreground-output gap details.
- Keep the STATUS/help equality and metadata-derived total assertions strict.
- Map only `resources` and `userns_mode` to their canonical grouped spans; all
  other current service attributes still require their exact code span.
- Sort only the observation in the test whose production lookups run
  concurrently; no runtime ordering is changed.
- Remove the restored upstream registry from the pending-enabler summary and
  retain the remaining foundation gaps explicitly.
