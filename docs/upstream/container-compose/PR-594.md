# Pull request 594: replace Nextflow with a recoverable native graph

## Change

This pull request replaces the separate Nextflow and Java build runtime with a
small Make dependency graph. SwiftPM and Go remain the source build tools. Each
successful repository build atomically publishes an authenticated source,
dependency, build-contract, and artifact pin that downstream repositories find
and consume automatically.

Retries reuse only exact valid pins and retained native compiler caches. A
changed source, remote, toolchain contract, dependency receipt, or artifact
invalidates only that repository and its transitive consumers. One
non-blocking lock covers every writer and final stack-bundle publication.

The stable release gate retains candidate-keyed exact-input checkpoints and
durable logs. Its checkpoint and authority receipts are flushed to stable
storage before success is reported.

## Scope boundary

Ordinary source builds do not sign applications, start virtual machines, open
Keychain or privacy prompts, run CodeQL or DocC, execute parity benchmarks, or
perform release packaging. Those operations remain explicit release-only
stages.
