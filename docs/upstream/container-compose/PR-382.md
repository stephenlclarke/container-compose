# Pull request 382: reserve CodeQL for stable releases

## Summary

Pull request [`#382`](https://github.com/stephenlclarke/container-compose/pull/382) closes tracking issue [`#381`](https://github.com/stephenlclarke/container-compose/issues/381).

- Restrict the package-graph CodeQL job to stable tag publication.
- Permit Current packaging to continue when CodeQL is intentionally skipped.
- Omit stable-only CodeQL badges and polling from mutable Current quality snapshots.
- Preserve the bounded wait for exact Current SonarQube metric indexing.
- Require successful fail-fast preflight in both lanes and successful CodeQL for stable tags.
- Stop package publication when the workflow is cancelled.

## Failure boundary

Current packaging cannot bypass failed preflight or workflow cancellation. Stable packaging cannot bypass failed preflight, cancellation, or failed/skipped CodeQL. Only the Current branch lane accepts the deliberate CodeQL skip; its quality snapshot remains backed by exact-commit SonarQube evidence.
