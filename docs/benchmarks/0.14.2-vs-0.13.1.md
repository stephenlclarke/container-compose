# Published release benchmark: 0.14.2 versus 0.13.1

This report compares immutable, Developer ID-signed release archives. No source product was built by the benchmark workflow. Both releases ran on the same host against the same Docker installation; Docker-normalized change is included to expose host drift.

## Result

Across 23 scored fixed-work fixtures, the Docker-normalized geometric-mean median changed -15.6% and the Docker-normalized geometric-mean P95 changed -13.9%. With a ±5% noise band applied to the normalized median, 17 fixtures improved, 6 stayed within noise, and 0 regressed.

Lower durations and negative changes are better.
